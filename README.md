# 🎨 (주)가울 Image Master Pro

> **온라인 쇼핑몰 상품 등록을 위한 고성능 이미지 처리 & 최적화 웹앱**  
> 스마트스토어, 쿠팡, 오픈마켓 셀러 및 MD를 위해 특화된 상세페이지 병합, HTML 이미지 추출, 썸네일 규격화 및 WebP 초고속 압축 스위트입니다.

---

## ✨ 핵심 기능

1. **📁 스마트 상세페이지 병합기 (Detail Page Stitcher)**
   - 여러 장의 분할된 상세페이지 이미지를 드래그 앤 드롭으로 순서 변경 및 결합
   - 쇼핑몰 규격 프리셋 지원 (스마트스토어 860px, 쿠팡 780px, 오픈마켓 1000px, 원본 유지)
   - 초대형 이미지(60,000px 이상)도 브라우저 메모리 엔진으로 0.1초 만에 즉각 렌더링
   - 스마트 슬라이스 분할 ZIP 다운로드 (10,000px 등 쇼핑몰별 높이 제한 대응)

2. **🔗 HTML 소스 이미지 추출기 (HTML Image Extractor)**
   - 상세설명 HTML 코드를 붙여넣으면 모든 `<img>` 이미지를 자동 파싱 및 썸네일 그리드로 시각화
   - 불필요한 배너/아이콘을 제외하고 원하는 이미지만 골라내어 상세페이지 병합기로 원클릭 전송

3. **🎨 상품 썸네일 & 배너 규격화 스튜디오 (Thumbnail Studio)**
   - *(※ AI 생성 기능 완전 제외, 순수 그래픽 툴)*
   - 오픈마켓 표준 규격 캔버스 (1000×1000, 800×800, 640×640, 16:9 배너)
   - 비율 유지 여백(Padding) 조절 및 꽉 채우기 모드
   - 단색/소프트 그레이/베이지/투명 배경 스타일링
   - 이커머스 프로모션 뱃지 오버레이 (BEST, HOT, 무료배송, 특가할인 등) 및 워터마크 지원

4. **⚡ WebP 포맷 일괄 변환 & 용량 다이어트 (Image Optimizer)**
   - 여러 장의 이미지를 차세대 고압축 WebP 포맷으로 일괄 변환 (최대 70~80% 용량 절감)
   - 실시간 용량 절감율 비교 및 전체 ZIP 일괄 다운로드

## 🚀 빠른 시작 (로컬 실행)

### 방법 1. 원클릭 실행 (Windows)
루트 디렉터리의 `start.bat` 파일을 더블 클릭하면 백엔드와 프론트엔드가 자동으로 실행되고 브라우저가 열립니다.

### 방법 2. 수동 실행
```bash
# 1. 백엔드 실행 (터미널 1)
pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --port 8000

# 2. 프론트엔드 실행 (터미널 2)
cd frontend
npm install
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속합니다.

## 🌐 Vercel 배포 가이드

본 프로젝트는 Vercel 단일 프로젝트로 프론트엔드와 Python Serverless API가 함께 배포되도록 구성되어 있습니다.

1. GitHub 저장소(`webimg`)에 코드를 Push합니다.
2. [Vercel](https://vercel.com/) 대시보드에서 `Add New Project`를 누르고 해당 GitHub 저장소를 Import합니다.
3. 빌드 설정:
   - **Framework Preset**: Vite
   - **Root Directory**: `./` (기본값)
4. `Deploy` 버튼을 클릭하면 1분 내로 배포가 완료되며 고유 도메인이 생성됩니다!
